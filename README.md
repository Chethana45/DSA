## ⏱️ Complexity Analysis

Whenever possible, I analyze solutions using:

### Time Complexity

How the running time changes as the input size increases.

Example:

```text
O(n)
O(log n)
O(n log n)
O(n²)
```

### Space Complexity

How much additional memory is required.

Example:

```text
O(1)
O(n)
O(n²)
```

Understanding complexity helps me compare different approaches and improve inefficient solutions.
